# NOIR INK — Site demonstrativo de estúdio de tatuagem

## Testar
Abra `index.html` no navegador. É um site estático, sem instalação e sem custos obrigatórios.

## Personalizar
Edite `config.js` para alterar nome, cidade, endereço, horário, Instagram e número de WhatsApp (DDD + número). O botão de orçamento só abre o WhatsApp depois que o número for configurado.

Edite `index.html` para mudar textos, estilos e URLs das imagens. **As fotos atuais são apenas referências ilustrativas e não representam trabalhos reais de um estúdio.** Antes de vender, substitua pelas fotos autorizadas do cliente e confira o direito de uso das imagens. Fontes e imagens externas dependem de conexão à internet.

## Publicar gratuitamente no GitHub Pages
1. Crie um repositório público `noir-ink-demo`.
2. Envie `index.html`, `config.js` e este LEIA-ME diretamente à raiz do repositório.
3. Acesse Settings > Pages, escolha Deploy from a branch, branch `main` (ou a branch principal exibida) e `/ (root)`.
4. Após a implantação, acesse `https://SEU-USUARIO.github.io/noir-ink-demo/`.

## Escopo comercial
Esta página é uma demonstração fictícia. Não há sistema de agendamento, banco de dados ou checkout; o botão direciona para WhatsApp quando configurado. Ajuste textos sobre técnicas e procedimentos às práticas reais do estúdio.
